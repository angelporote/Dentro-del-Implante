# Dentro-del-Implante
Web interactiva en 3D para estudiar biomateriales e implantología. Desmonta una prótesis de cadera, recorre seis vitrinas (historia, materiales, interfaz, ortopedia, cardio y normativa) y entra en cada sala para practicar. Hecha con Three.js por y para estudiantes de Ingeniería Biomédica.
